# Sift

iPhone app that shows only Instagram DMs and YouTube Subscriptions.
It loads both mobile sites in its own web views. It blocks Home, Explore, Reels and Shorts
by URL (`Sift/Router.swift`) and hides leftovers with injected CSS/JS (`Sift/Resources/`).

- Build: GitHub Actions (`.github/workflows/ios.yml`) runs the tests and uploads to TestFlight.
- Setup: see [SETUP.md](SETUP.md).
- Project file is generated by XcodeGen from `project.yml`.
